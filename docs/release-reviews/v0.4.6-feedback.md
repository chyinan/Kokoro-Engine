## Privacy boundary

Kokoro Engine does not collect automatic remote analytics. The application does
not send release downloads, setup progress, support events, registry downloads,
submissions, repeat participation, or AstrBot usage to a Kokoro analytics
endpoint. This snapshot uses only public GitHub Release asset counters.
