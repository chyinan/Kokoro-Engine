# R04 首次引导

状态：已完成静态审查和现有前端回归；真实 provider、干净机器和 Tauri 安装版未执行。

## 调用链与契约

- `src/features/onboarding/onboarding-flow.ts` 管理 language→character→provider→connection-test→chat 阶段；只有首个成功回复才写入完成状态。
- `src/features/onboarding/provider-setup.ts` 与 `provider-setup-core.ts` 生成 provider 配置，凭据保持 app-level；`src/ui/widgets/onboarding/ProviderSetupStep.tsx` 负责表单、测试连接和错误展示。
- `src/features/onboarding/onboarding-turn-correlation.ts`、`onboarding-chat-cancellation.ts` 过滤迟到事件并在取消时结束引导回合；`OnboardingOverlay.tsx` 将状态接入主界面。
