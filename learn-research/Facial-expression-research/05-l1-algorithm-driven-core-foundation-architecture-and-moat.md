# L1 内置情感证据算法：边界、数学与维护方案

> 状态：2026-09-14 再审后的设计基线，尚未实现或完成性能、准确率验证。算法常数是待校准候选值，不是实测结论。跨层契约以 [03 总体架构](03-facial-expression-technical-selection-and-architecture-design.md) 为准；现状见 [01 源码审计](01-current-emotion-to-expression-pipeline-analysis.md)，需求见 [02 需求与评审](02-facial-expression-requirements-and-adversarial-review.md)，可选模型见 [04 L2 设计](04-lightweight-local-onnx-emotion-models-and-integration-design.md)。

## 1. 决策与非目标

L1 是默认内置、无需另行下载模型的文本证据提取器。它为提交被接受后的倾听反应提供低成本线索；L2 只能在有效期限内补充同一输入的证据，L1 不等待它。聊天、TTS 和已有表情功能不得依赖 L1 成功。

文本的情感倾向不等于用户真实心理状态，也不直接决定角色应该做什么表情。无匹配、歧义、缺失上下文和明确中性必须区别处理；不能用 neutral 掩盖算法失败。对于引用、讽刺、攻击、悲伤等语境，默认保守倾听，避免机械模仿用户的愤怒或悲伤。

本期不承诺识别全部反讽、推导认知意图、跨语言等准确、自动生成 FACS 或证明商业护城河。不新增情感记忆持久化、用户对话自动采集、云端自动蒸馏和 OTA 词库通道。可积累的资产是可追溯规则、标注规范、失败样本和稳定接口。

## 3. 领域边界与唯一所有者

```mermaid
flowchart LR
    Input[已接受的输入与请求身份] --> Boundary[有界文本适配]
    Boundary --> L1[L1 无状态证据函数]
    Boundary --> L2[L2 可选后台推理]
    L1 --> Evidence[PerceptionEvidence]
    L2 --> Evidence
    Evidence --> Gate[身份与期限校验]
    Gate --> Policy[ResponsePolicy 角色反应策略]
    Policy --> State[FaceState 回合状态与惯性]
    State --> Adapter[模型能力与参数映射]
    Adapter --> UPB[UPB 唯一逐帧平滑与合成]
    UPB --> Render[经验证的最终提交位置]
```

| 模块 | 拥有的数据和职责 | 禁止承担的职责 |
| --- | --- | --- |
| 输入适配 | 保留请求身份；有界规范化；记录截断 | 监听全局键盘或把未发送草稿当新回合 |
| L1 | 只读词库、匹配、修饰、证据聚合；相同输入和版本产生相同结果 | 角色配置、时钟、回合历史、IPC、FACS、Live2D 写入、逐帧平滑 |
| ResponsePolicy | 将有效证据与只读角色配置转换为反应候选；共情、幅度和禁用策略 | 保留上轮情绪或运行计时器；改变用户文本证据 |
| FaceState | 唯一管理当前角色/回合、来源优先级、截止时间、驻留与衰减 | 分词、下载模型、直接操作渲染参数 |
| UPB | 唯一逐帧平滑、通道仲裁与最终合成 | 重新理解文本、再次执行人格变换或维护第二套回合惯性 |
| 模型适配 | 参数存在性、默认值、范围和资产能力；降级到已知可用预设 | 假设所有模型都有标准 FACS AU 或固定参数范围 |

`PerceptionEvidence` 的字段、来源枚举及身份封套在 03 中唯一声明。L1 输出语气/极性证据及 status、truncated；覆盖率、输入修复和匹配分数仅作 provider 内部诊断，不新增未声明的 wire 字段，不生成第二套 `NormalizedExpressionFrame`。词典分数只能叫启发式得分，未经标注集校准不能解释为概率或与 L2 softmax 直接比较。

L1 和 L2 都经过相同 ResponsePolicy 与 FaceState。迟到 L2、取消回合、角色激活代际变化、模型代际变化或新回合均由身份门禁拒绝；清理和失效不受情绪驻留门槛限制。具体键及接纳条件见 03，不在 L1 内复制状态机。

## 4. 输入边界与确定性匹配

以下是首版候选策略，须在语料回放后确认，L1/L2 的共同入口一致：

1. 在规范化前以逐 Unicode 标量的有界扫描截取 UTF-8 编码不超过 **2048 bytes** 的前缀；不要先对任意长字符串整体编码或规范化。JavaScript 的 UTF-16 长度不能当作字符数；孤立代理项按统一替换策略变为 U+FFFD，并记录输入被修复。
2. 对该有界前缀执行 NFC，再保留最多 **512 Unicode scalars**。标量边界不是字素簇边界，截断可能分开组合序列或 Emoji ZWJ 序列；这时降低证据质量，不能声称完整保留视觉字符。
3. NFC 不合并所有全角/半角形式。只采用版本化的显式别名规则，避免不受控规范化改变引用或否定语义。
4. 截断只影响表情分析副本，完整聊天文本照常发送。标记截断与上下文丢失；截断、未闭合引用或句法不完整时保守弃权，不基于片段升级为强反应。L2 另以 **64 tokens（含特殊 token）** 为候选上限，不以字符数替代 tokenizer 长度。
5. 对空串、控制字符主导、未知语言或未匹配返回无充分证据；已知中性与失败/缺失分开。

AC 的输出敏感复杂度写为 **O(N + Z)**，其中 N 是扫描长度，Z 是枚举匹配数；构建成本和内存另计。全量重叠匹配可能令 Z 很大。候选每请求最多枚举 1024 个匹配，命中预算耗尽即返回受限结果并弃权，不能静默把前 1024 项作为完整证据。需要在枚举时限制，不能先收集全部命中再截断。

重叠候选按左端点从小到大、同起点最长词条、显式优先级、稳定词条 ID 固定排序，接受一项后跳到其末端，不再消费相交区间；否定/程度词作为修饰 token，不重复作为情感证据。英文有单词边界，中文/日文需要独立规则包；“前 3 词”必须指已定义的 token 序列，不能把三种语言统一按空格切词。

实现可以从有界、可测试的简单匹配器起步，以基准决定是否引入 AC、DAT 或二进制词库。预分配缓冲只能减少部分分配，不能保证 JavaScript NFC、返回对象或运行时无 GC。TypeScript、Rust、WASM 需要各自实现与一致性测试，不存在把 TypeScript 直接编译为 Rust 的自动同构保证。

## 5. 有界数学方案

以下公式是可验证工程启发式，不是通用心理学模型。内部向量域记为：

$$\mathcal D=[-1,1]\times[0,1]\times[-1,1],\qquad \mathbf u_i=[V_i,A_i,D_i]^T.$$

只有得到版本化标注支持的轴才参与；缺失 dominance 不能伪装成模型实际预测。若使用中性占位，适配结果必须保留该轴的缺失信息，策略不得据此推导支配性反应。所有配置和输入在边界检查有限值、维数和范围，非有限值不得进入滤波器。

### 5.1 局部修饰

否定只调制效价 V，不能把唤醒度 A 乘成负数。候选否定窗口为前三个已定义 token，遇句界停止；引用内外隔离，词条可定义例外。距离衰减系数采用版本化表，满足 `0 < r(d) <= 1`：

$$\eta_i=\prod_{j\in\mathcal N_i}[-r(d_j)],\qquad\eta_i=1\ \text{when}\ \mathcal N_i=\varnothing.$$

双重否定反转和讽刺不是相同现象。无法解释的作用域不强行用乘积判决，标记歧义并弃权。

程度增益使用有限窗口内的贡献和，并显式截断；Sigmoid 本身不能限制任意多个修饰词的总和：

$$g_i=\operatorname{clamp}(1+\sum_{b\in\mathcal B_i}\delta_b,\ 0.3,\ 2.2).$$

边界 0.3 与 2.2 只是候选配置。修饰后的单项为：

$$\tilde{\mathbf u}_i=[\operatorname{clamp}(\eta_i g_i V_i,-1,1),\operatorname{clamp}(g_i A_i,0,1),D_i]^T.$$

不默认“否定开心”就等于“悲伤”；最终标签还需类别证据和质量门禁。转折采用非负权重：候选前句 0.5、后句 1.0；嵌套、重复转折不递归相乘，无法切分时退回相同权重并降低质量。这些常数与原文中 0.35/1.85 等未校准值不同时生效。

### 5.2 聚合

情感词、Emoji、颜文字都作为有界证据项参与。标点只能增强已有证据的有限权重，不能单独把问号解释成强负面情感。同一模式的重复出现设定有限贡献，防止刷屏放大。

$$\mathbf v=\begin{cases}\displaystyle\frac{\sum_i q_i\tilde{\mathbf u}_i}{\sum_i q_i},&\sum_i q_i>0\\\text{no evidence},&\text{otherwise}\end{cases},\qquad q_i\ge0.$$

实现限定每项 q 在 [0,1]、项数不超过 1024，同一词条 ID 的重复贡献封顶，避免有限但极大权重求和溢出。非负权重的凸组合保留坐标域，最后仍做有限值检查与逐轴钳制。不能再除以 `sqrt(sum(q_i^2)+epsilon)`：重复 n 个同向词时原公式会增长为 sqrt(n)，破坏归一化；无词而有标点时，除以极小 epsilon 还会放大噪声。

聚合均值可能掩盖相反情绪，所以独立保留冲突/覆盖信息。高冲突触发 ambiguous，不把均值接近零直接判成确信的 neutral。类别得分与连续坐标需要分别校准；坐标不提供 FACS 的唯一解。

### 5.3 人格策略与会话惯性

人格仿射变换保留为 **ResponsePolicy 中的可选表达实验**：

$$\mathbf r=\Pi_{\mathcal D}(W_p\mathbf v+\mathbf b_p).$$

D 缺失时只使用 VA 子矩阵，禁用 D 行列与偏置、不输出 D；三轴都有依据时才允许完整 3×3 变换，不能用占位 D 隐式改变 V/A。

`W_p`、`b_p` 只改变角色反应候选，不回写证据。采用版本化的有限范围、严格维度校验；错误配置用默认策略。默认矩阵为单位阵、偏置零；不内置“傲娇必然反向效价”等人格刻板行为。角色配置仍遵循现有序列化激活与 prepare/apply/commit 所有者，L1 不自行持久化覆盖项。矩阵是否启用需经过角色作者和体验评测，不能替代情境理解。

惯性仅在 FaceState 中实现，绕当前角色基线 b 衰减，而不是把所有轴衰减到零：

$$\mathbf e(t)=\mathbf b+(\mathbf e_0-\mathbf b)2^{-\Delta t/\tau_h}.$$

半衰期候选 `tau_h = 8 s`，仅供调参，不表示生理测量。事件失效、角色切换、取消及来源接管按 03 优先处理；可配置无输入 TTL 到期后回基线。TTL 与指数衰减分别负责清理与过渡，不再同时规定“30 秒线性归零”和“15 秒强制话题重置”。不以“早安”单个关键词可靠识别话题变化。

### 5.4 逐帧平滑

只在 UPB 内对获准平滑的表情通道采用一阶指数低通：

$$\alpha=1-e^{-\Delta t/\tau_s},\qquad\mathbf y_{next}=\mathbf y+\alpha(\mathbf target-\mathbf y).$$

`dt` 为渲染端单调时钟产生的非负秒数，`tau_s > 0`；负数/NaN 输入拒绝，长时间挂起恢复时重置为当前有效目标，不能追赶旧动画。时间常数候选 0.10 s；恒定目标从静止达到约 95% 需要约 `3*tau_s`，不能宣称 80–120 ms 内完成。

这是**一阶滤波**，不是临界阻尼二阶弹簧，也不再叠加另一套 L1 ADSR 包络。音频口型使用其独立时间轴与已有处理，不能因全通道套用低通而新增声画滞后。每帧只允许最终合成写者提交模型值，通道规则见 03。

## 6. 数据、基准与发布门禁

仓库尚无与本方案匹配的已验证万例黄金集，也无准确率 92.5%/93.5%、0.08 ms 或零内存分配的测量依据。原报告这些数字不作为现状、承诺或发布门禁。

词库源文件应记录语言、词条 ID、许可来源、版本、适用边界、向量/类别证据、修饰规则和审核记录。首先随应用版本发布可读数据；只有基准证明必要时才引入 `.kac` 二进制格式。若引入，另定魔数、版本、字节序、长度/offset 检查、最大节点数、哈希和回滚方案，禁止未经验证的 TypedArray 视图直接读取任意包。

### 6.1 语料与效果

- 用自编或许可清楚的中文/日文/英文样本，分语言、类别、否定、转折、引用、混合情绪、讽刺、普通中性和无证据场景分层。记录允许弃权的标签和分歧裁决，不强迫所有句子只有一个情绪答案。
- 开发、校准、冻结盲测分离；按来源/模板族去重和切分，避免同一例句换一个词就横跨训练和盲测。性能恶意输入集另列，不计入语义准确率分母。
- 报告每语言/类别 macro-F1、混淆矩阵、弃权覆盖率、错误强反应率；有标注支持的连续轴报告 MAE。L1 与 L2 比较同一盲测集，不能挑选各自最好数据。
- LLM 可辅助生成待审核候选，输出不是黄金真值。标注人员复核、许可检查、敏感数据排除和盲测隔离是必要门禁。私密会话不自动上传或用于闭环。
- 发布阈值在首轮基线与体验风险评估后登记并冻结；确有纠错时允许说明原因地修改旧标签，不要求“永远零变化”。

### 6.2 性能候选预算

| 指标 | 初始候选目标 | 计量范围与限制 |
| --- | --- | --- |
| L1 热态 P95 | <= 5 ms（统一采用 03） | 支持设备上，从有界入口到证据返回，包含规范化；尚未测量 |
| 初始化 | 单独报告 | 词库加载、编译、缓存及首次调用；不以热态平均值隐藏冷启动 |
| 资源 | 报告峰值、稳态和重复请求增长 | 词库、缓冲、返回对象、GC；不预称 0 MB 或 0 GC |
| 端到端可见反应 | 单独记录分位数 | 接受发送、调度、策略、下一渲染帧均计入，不用 L1 函数耗时替代 |

记录 CPU、操作系统、WebView/JS 版本、电源模式、样本长度/语言、预热策略、负载及重复次数。低端设备超预算时缩小规则或使用中性倾听；目标不能保证系统调度或 60 FPS。L2 接受预算统一由 03 定义，资源验收由 04 细化。

### 6.3 必须覆盖的性质与回归场景

| 场景 | 应验证的结果 |
| --- | --- |
| `[.8,.6,.2]` 被一次否定 | A 不为负，坐标均有限且在域内 |
| 同向词重复与无词标点 | 不发生 sqrt(n) 放大或 epsilon 除法放大 |
| 无命中/相反证据/明确中性 | 分别表示缺失、歧义、中性，不能混为一个强置信结果 |
| NaN、Infinity、非法矩阵 | 安全拒绝或默认策略，不能污染后续帧 |
| 边界 2048 bytes / 512 scalars | 码点安全、有截断标志，原聊天文本完整 |
| 代理对、孤立代理项、组合字符、ZWJ、全角 | 规范化策略确定，歧义保守，不宣称字素簇完整 |
| 重叠词、重复模式、命中预算耗尽 | 固定排序、有界处理、受限结果弃权 |
| 相同文本+词库版本重复运行 | L1 结果一致，上一角色/上一回合不影响输出 |
| L2 迟到、取消、切角色、重载模型 | FaceState/接纳门禁丢弃；不能越过驻留锁污染当前表情 |
| 30/60/144 Hz 与暂停恢复 | UPB 时间常数一致；恢复不重播旧目标，无二次平滑 |
| 词库加载失败 | 维持普通倾听与既有聊天/TTS，记录可诊断故障 |

## 7. 再审决议与实施顺序

本轮保留“规则修饰、可选神经补充、数据与算法分离”的路线，驳回“L1 包办人格、会话与逐帧渲染”和“未经测量即宣称工业级零崩溃”的结论。删去模拟批准签名，后续真实交叉审查结果由综合评审记录记录。

实施顺序为：先落实 03 的唯一契约和失效门禁；再实现最小 L1 与性质测试；随后建立分层人工审核基线；最后根据失败样本选择 AC/词库扩充、人格实验及 L2。每一步允许独立关闭并回退到已知可用倾听行为，不以扩充算法为删除既有功能的前提。
