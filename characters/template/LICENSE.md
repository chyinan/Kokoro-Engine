# Character package license

This file is a starting point for a creator package. Replace it with the
complete license text that applies to every file in the package before
submission.

The `license` value in `character.json` must identify the same license. Use an
SPDX identifier when one exists, such as `MIT`, `CC-BY-4.0`, or `CC0-1.0`.
Include separate license notices for bundled avatar, background, voice, or
Live2D files when their terms differ from the character text.

Do not submit assets unless you have the right to redistribute them in a
Kokoro Engine package. A creator's name, source URL, and attribution terms
should be recorded here even when the asset license is permissive.
